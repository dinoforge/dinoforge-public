DinoForge Cookie Bridge 개인정보처리방침

최종 수정일: 2026-08-29

수집·처리하는 정보

DinoForge Cookie Bridge는 사용자가 현재 탭에서 명시적으로 전송을 요청한 지원 사이트의 쿠키와 세션 정보를 처리합니다. Novel Analyzer 연결에는 필요한 localStorage 세션 상태가 포함될 수 있습니다. 이 정보는 로그인 상태를 사용자의 DinoForge 앱에서 재사용하기 위한 목적으로만 사용합니다.

전송 및 저장

수집한 쿠키와 세션 정보는 외부 서버, 광고 네트워크 또는 분석 서비스로 보내지 않습니다. 확장 프로그램은 사용자의 컴퓨터에서 실행 중인 다음 로컬 브리지로만 전송합니다.

  • Media Downloader: 127.0.0.1:16975
  • Novel Analyzer: 127.0.0.1:47831

Media Downloader에서 사용자가 선택한 경우에만 쿠키를 cookies.txt 파일로 사용자의 로컬 컴퓨터에 저장합니다. 확장 프로그램 자체에는 원격 코드가 없으며, 전송한 정보의 별도 서버 보관이나 판매를 하지 않습니다.

사용자 선택과 삭제

전송은 사용자가 확장 팝업에서 앱 버튼을 눌렀을 때만 수행됩니다. 사용자는 브라우저의 확장 프로그램 관리 화면에서 언제든지 확장 프로그램을 삭제할 수 있습니다. 로컬 앱이 보관하는 데이터는 해당 앱의 설정과 삭제 절차를 따릅니다.

권한 사용

cookies와 지원 사이트 호스트 권한은 로그인 쿠키를 읽기 위해, activeTab과 tabs는 현재 탭의 지원 사이트를 확인하기 위해, scripting은 사용자가 선택한 Novel 세션 상태를 읽기 위해 사용합니다. downloads는 사용자가 요청한 cookies.txt 로컬 저장에만 사용합니다.

문의

정책 또는 개인정보 처리에 관한 문의는 공개 정책 저장소의 Issue tracker에 남겨 주세요. 민감한 쿠키, 토큰, 비밀번호는 이슈에 포함하지 마세요.
