DinoForge Cookie Bridge 개인정보처리방침

최종 수정일: 2026-09-27

수집·처리하는 정보

DinoForge Cookie Bridge는 사용자가 현재 탭에서 명시적으로 전송을 요청한 지원 사이트의 쿠키와 세션 정보를 처리합니다. Novel Analyzer 연결에는 필요한 localStorage·sessionStorage 세션 상태와 로그인 여부를 나타내는 pageAuthenticated boolean이 포함될 수 있습니다. 계정명이나 페이지 본문은 전송하지 않습니다. 이 정보는 로그인 상태를 사용자의 DinoForge 앱에서 재사용하기 위한 목적으로만 사용합니다.

전송 및 저장

수집한 쿠키와 세션 정보는 외부 서버, 광고 네트워크 또는 분석 서비스로 보내지 않습니다. 확장 프로그램은 사용자의 컴퓨터에서 실행 중인 다음 로컬 브리지로만 전송합니다.

  • Media Downloader: 127.0.0.1:16975
  • Novel Analyzer: 127.0.0.1:47831
  • Hitomi Downloader: 127.0.0.1:6009 (별도 API 스크립트 설치 필요)

Hitomi Downloader adapter는 원본 extractor에서 사용하는 Hitomi·E-Hentai·ExHentai·Hiyobi·Pixiv의 명시적 HTTPS host에서만 동작합니다. 확장 팝업을 열면 연결 확인을 위해 현재 URL을 /valid_url로 조회하고, 사용자가 현재 페이지 다운로드 또는 쿠키 업데이트를 눌렀을 때만 Hitomi Downloader의 loopback HTTP API(/download, /cookie)로 전달합니다. 다른 사이트의 쿠키나 URL 작업 데이터는 전송하지 않습니다.

Media Downloader에서 사용자가 선택한 경우에만 쿠키를 cookies.txt 파일로 사용자의 로컬 컴퓨터에 저장합니다. 확장 프로그램 자체에는 원격 코드가 없으며, 전송한 정보의 별도 서버 보관이나 판매를 하지 않습니다.

사용자 선택과 삭제

전송은 사용자가 확장 팝업에서 앱 버튼을 눌렀을 때만 수행됩니다. 사용자는 브라우저의 확장 프로그램 관리 화면에서 언제든지 확장 프로그램을 삭제할 수 있습니다. 로컬 앱이 보관하는 데이터는 해당 앱의 설정과 삭제 절차를 따릅니다.

권한 사용

cookies와 지원 사이트 호스트 권한은 로그인 쿠키를 읽기 위해, activeTab과 tabs API는 지원 사이트 탭을 확인하기 위해 사용합니다. scripting은 사용자가 선택한 Novel 세션 상태를 읽기 위해 사용합니다. cookies.txt 저장은 브라우저의 표준 파일 다운로드 동작만 사용하며 다운로드 관리 권한을 요청하지 않습니다.

문의
