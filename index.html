Stream Recorder 개인정보처리방침

최종 수정일: 2026-10-03

이 개인정보처리방침은 Stream Recorder Chrome 확장 프로그램에 적용됩니다.

처리하는 정보

확장 프로그램은 HTTP 또는 HTTPS 페이지에서 HLS 리디렉션을 찾기 위해 접근 가능한 프레임의 Fetch/XHR 응답을 관찰합니다. HLS로 식별된 요청의 최종 URL은 프레임별 페이지 메모리에 최대 30개까지 임시 보관될 수 있으며, 이 관찰만으로 확장 프로그램이 새 네트워크 요청을 만들지는 않습니다. 사용자가 HLS 확인 또는 전체 다운로드를 시작한 뒤에만 후보 URL을 확장 프로그램으로 전달해 안전 검사를 하고, 선택된 재생목록·조각을 요청합니다. 영상·요청 본문, 쿠키, 인증 헤더는 이 관찰기에서 읽거나 저장하지 않으며, 노출된 Content-Type은 HLS 여부 판별에만 사용합니다.

저장과 전송

녹화 조각과 세션 정보는 Chrome 저장소, IndexedDB, OPFS 등 사용자의 브라우저 로컬 저장소에서 처리됩니다. 팝업에서 MP4 또는 MKV 출력 형식을 선택할 수 있고 선택은 일반 녹화와 HLS 저장에 적용됩니다. 사용자가 HLS VOD 전체 다운로드 또는 라이브 녹화를 시작하면 현재 탭의 접근 가능한 프레임에서 발견된 재생목록과 그 안에 지정된 미디어 조각을 해당 스트리밍 호스트에 요청합니다. master playlist에서는 사용자가 화질을 선택할 수 있고, VOD는 분리 오디오 rendition도 선택할 수 있습니다. 브라우저에서 허용하는 해당 호스트의 쿠키가 요청에 포함될 수 있으며, 전체 프레임 URL 대신 해당 프레임의 origin을 Referer로 사용합니다. 라이브 녹화는 미디어 순번으로 새 조각을 추적하고, 사용자가 중지하거나 4시간 또는 50,000개 조각 상한에 도달하면 마무리합니다. fMP4·MPEG-TS 입력은 Mediabunny Worker에서 로컬로 선택한 컨테이너에 remux하며 재인코딩하지 않습니다. 호환되지 않는 코덱·트랙 조합은 변환을 거부합니다. 결과 파일은 Chrome 다운로드를 통해 사용자의 장치에 저장됩니다.

영상 본문은 개발자 서버로 전송하지 않으며 분석·광고 서버도 사용하지 않습니다. HLS 다운로드의 미디어 요청은 재생목록에 명시된 스트리밍 호스트로 직접 전송되며, 요청 URL의 서명 query는 해당 호스트에 전달될 수 있지만 확장 프로그램의 영속 세션·진단 로그에는 기록하지 않습니다. 재시도에 필요한 원본 재생목록 주소와 체크포인트는 offscreen 문서의 메모리에만 머물며, 브라우저가 완전히 재시작되면 이어받기에 사용할 주소는 복원되지 않습니다. 진단 정보에는 영상 조각, 쿠키, 인증 헤더를 포함하지 않으며 URL의 사용자 이름·비밀번호·query·hash를 제거합니다.

DRM 및 이용 권한

DRM 또는 암호화 키 표식이 있는 HLS 재생목록은 저장하지 않습니다. 라이브 녹화는 미디어 순번을 안전하게 추적할 수 있는 비암호화 단일/멀티플렉스 스트림만 지원하며 분리 오디오는 저장하지 않습니다. 로그인·지역·DRM 제한을 우회하지 않으며 권한 있는 미디어에 한해 사용해야 합니다. 표준 manifest 구조나 사이트 접근 정책이 다르면 지원되지 않을 수 있고 모든 사이트 호환을 보장하지 않습니다. 실패 시 이미 저장한 fMP4 조각은 Recovery Center에서 부분 복구할 수 있으며, Chrome 다운로드가 중단되면 이미 결합한 임시 MP4/MKV를 다시 저장할 수 있습니다. 라이브 녹화는 브라우저 재시작 후 자동 재개되지 않습니다. MPEG-TS 조각 수집 도중 브라우저가 재시작되면 partial TS는 Recovery Center에서 복구되지 않으며, 저장되지 않은 원격 구간은 다시 받거나 복구하지 않습니다.

광고와 프로파일링

처리 정보를 판매하거나 광고·프로파일링에 사용하는 기능은 없습니다.

보관과 삭제

녹화 세션과 임시 조각은 복구 또는 다운로드 완료 확인을 위해 브라우저에 남을 수 있습니다. 사용자가 자동 정리 옵션을 선택한 경우에도 다운로드 완료가 확인된 뒤에만 해당 임시 데이터가 정리됩니다. 그 외 정리는 관리 화면에서 사용자가 확인한 항목에 대해서만 수행됩니다. 녹화 중이거나 복구가 필요한 세션은 자동으로 삭제하지 않습니다.
