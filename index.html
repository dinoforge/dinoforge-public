Stream Recorder 개인정보처리방침

최종 수정일: 2026-08-28

이 개인정보처리방침은 범용 Stream Recorder Chrome 확장 프로그램에만 적용됩니다. AniLife 전용판에는 적용되지 않습니다.

처리하는 정보

사용자가 녹화를 직접 시작한 경우에만 선택한 탭의 URL·제목과 해당 페이지에서 재생되는 영상·오디오 데이터를 처리합니다. 이 정보는 녹화 세션 식별, 파일명 생성, 중복 방지, 상태 표시와 복구에 사용됩니다.

저장과 전송

녹화 조각과 세션 정보는 Chrome 저장소, IndexedDB, OPFS 등 사용자의 브라우저 로컬 저장소에서 처리됩니다. 결합된 MP4는 Chrome 다운로드를 통해 사용자의 장치에 저장됩니다.

현재 범용판은 영상 본문, 전체 URL query, 쿠키 또는 인증정보를 개발자 서버나 제3자에게 전송하지 않습니다. 진단 정보에는 영상 조각, 쿠키, 인증 헤더를 포함하지 않으며 URL의 사용자 이름·비밀번호·query·hash를 제거합니다.

DRM 및 이용 권한

senc DRM 표식이 감지되면 MP4 저장을 차단합니다. DRM·로그인·지역 제한을 우회하거나 사라진 원격 구간을 다시 받는 기능은 제공하지 않습니다. 사용자는 녹화 권한이 있는 미디어만 저장해야 합니다.

광고와 프로파일링

처리 정보를 판매하거나 광고·프로파일링에 사용하는 기능은 없습니다.

보관과 삭제

녹화 세션과 임시 조각은 복구 또는 다운로드 완료 확인을 위해 브라우저에 남을 수 있습니다. 사용자가 자동 정리 옵션을 선택한 경우에도 다운로드 완료가 확인된 뒤에만 해당 임시 데이터가 정리됩니다. 그 외 정리는 관리 화면에서 사용자가 확인한 항목에 대해서만 수행됩니다. 녹화 중이거나 복구가 필요한 세션은 자동으로 삭제하지 않습니다.
