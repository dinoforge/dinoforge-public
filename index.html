Stream Recorder 개인정보처리방침

최종 수정일: 2026-08-25

이 개인정보처리방침은 범용 Stream Recorder Chrome 확장 프로그램이 현재 코드에서 처리하는 정보를 설명합니다. AniLife 전용판에는 적용되지 않습니다.

수집·처리 범위

확장 프로그램은 사용자가 녹화를 명시적으로 시작한 경우에만 선택한 재생 탭의 탭 정보와 페이지의 미디어 재생 데이터를 처리합니다. 녹화 대상은 페이지 플레이어가 MediaSource/SourceBuffer.appendBuffer()로 브라우저에 전달한 오디오·영상 조각이며, 원격 원본 파일을 별도로 다시 다운로드하는 방식이 아닙니다.

탭 제목과 URL은 녹화 항목 식별, 파일명 생성, 중복 녹화 방지와 복구 화면 표시에 사용됩니다. 진단 정보로 내보낼 때 URL의 사용자 이름·비밀번호·query·hash는 제거됩니다.

저장 위치와 결과 파일

녹화 조각과 세션 메타데이터는 사용자의 브라우저 로컬 저장소에서 처리됩니다. 현재 구현은 IndexedDB spool을 사용하고, offscreen Worker가 OPFS에 MP4 결합 결과와 checkpoint를 기록할 수 있습니다. MP4 결과는 Chrome downloads API를 통해 사용자의 장치에 저장됩니다.

외부 전송

현재 범용판 소스에는 개발자 서버로 영상 본문, 전체 URL query, 쿠키 또는 인증정보를 전송하는 코드가 없습니다. 진단 bundle에도 영상 조각 본문, 쿠키, 인증 헤더와 전체 query를 포함하지 않도록 정규화합니다.

DRM 및 권리

캡처 중 DRM 표식(senc)이 감지되면 MP4 저장을 차단합니다. DRM 보호를 우회하거나, 로그인·지역 제한을 우회하거나, 사라진 원격 구간을 다시 받는 기능은 제공하지 않습니다. 사용자는 녹화하려는 미디어에 대해 필요한 이용 권한과 저작권을 스스로 확인해야 합니다.

광고·판매·프로파일링

현재 코드에는 처리 정보를 판매하거나 광고·프로파일링에 사용하는 기능이 없습니다.

보관과 삭제

녹화 세션과 spool은 복구와 다운로드 완료 확인을 위해 브라우저 로컬 저장소에 남을 수 있습니다. 확장 프로그램의 관리 화면에서 복구 가능한 세션을 확인하고, 사용자가 확인한 정리 항목만 삭제할 수 있습니다. 브라우저의 확장 프로그램 데이터 삭제·제거는 Chrome의 저장소 정책을 따릅니다.

문의

개인정보 또는 데이터 처리에 관한 문의는 저장소의 GitHub Issues 또는 배포 페이지에 공개된 최신 연락처를 이용하십시오.
