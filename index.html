Stream Recorder 개인정보처리방침

최종 수정일: 2026-10-05

이 개인정보처리방침은 Stream Recorder Chrome 확장 프로그램에 적용됩니다.

동의와 처리 시점

처음 사용하거나 현재 고지 버전에 대한 동의 기록이 없으면 팝업과 녹화 관리 화면에 데이터 처리 항목과 목적을 먼저 표시합니다. 사용자가 위 내용에 동의하고 기능 켜기를 누르기 전에는 웹 페이지의 Fetch/XHR, MediaSource, URL 또는 미디어 데이터를 읽는 기능 코드를 주입하지 않으며 녹화 기능도 사용할 수 없습니다. 정적 동의 게이트는 페이지 URL·DOM·네트워크를 읽지 않고 확장 로컬 저장소의 동의 버전만 확인합니다. 동의 기록은 확장 프로그램의 로컬 저장소에만 둡니다. 동의한 뒤 현재 열려 있는 HTTP(S) 탭과 이후 열리는 HTTP(S) 프레임에서 페이지 처리 코드를 사용할 수 있습니다.

처리하는 정보

확장 프로그램은 HTTP 또는 HTTPS 페이지의 접근 가능한 프레임에서 HLS 리디렉션을 찾기 위해 Fetch/XHR 요청·응답 URL, 성공·리디렉션 여부와 필요한 경우 노출된 Content-Type을 확인합니다. 조건에 맞는 HLS 최종 URL은 프레임별 페이지 메모리에 최대 30개까지 임시 보관될 수 있으며, 관찰 자체는 새 네트워크 요청을 만들지 않습니다. 응답 본문, 쿠키와 인증 헤더는 이 관찰기에서 읽거나 저장하지 않습니다. 사용자가 팝업에서 HLS 확인·저장을 직접 시작한 뒤에만 후보 URL을 확장 프로그램으로 전달해 안전 검사를 하고, 선택한 재생목록·미디어 조각을 요청합니다.

저장과 전송

녹화 조각과 세션 정보는 Chrome 저장소, IndexedDB, OPFS 등 사용자의 브라우저 로컬 저장소에서 처리됩니다. 팝업에서 MP4 또는 MKV 출력 형식을 선택할 수 있고 선택은 일반 녹화와 HLS 저장에 적용됩니다. 사용자가 HLS VOD 전체 다운로드 또는 라이브 녹화를 시작하면 현재 탭의 접근 가능한 프레임에서 발견된 재생목록과 그 안에 지정된 미디어 조각을 해당 스트리밍 호스트에 요청합니다. master playlist에서는 사용자가 화질을 선택할 수 있고, VOD는 분리 오디오 rendition도 선택할 수 있습니다. 브라우저에서 허용하는 해당 호스트의 쿠키가 요청에 포함될 수 있으며, 전체 프레임 URL 대신 해당 프레임의 origin을 Referer로 사용합니다. 라이브 녹화는 미디어 순번으로 새 조각을 추적하고, 사용자가 중지하거나 4시간 또는 50,000개 조각 상한에 도달하면 마무리합니다. fMP4·MPEG-TS 입력은 Mediabunny Worker에서 로컬로 선택한 컨테이너에 remux하며 재인코딩하지 않습니다. 호환되지 않는 코덱·트랙 조합은 변환을 거부합니다. 결과 파일은 Chrome 다운로드를 통해 사용자의 장치에 저장됩니다.

영상 본문은 개발자 서버로 전송하지 않으며 분석·광고 서버도 사용하지 않습니다. HLS 다운로드의 미디어 요청은 재생목록에 명시된 스트리밍 호스트로 직접 전송되며, 요청 URL의 서명 query는 해당 호스트에 전달될 수 있지만 확장 프로그램의 영속 세션·진단 로그에는 기록하지 않습니다. 재시도에 필요한 원본 재생목록 주소와 체크포인트는 offscreen 문서의 메모리에만 머물며, 브라우저가 완전히 재시작되면 이어받기에 사용할 주소는 복원되지 않습니다. 진단 정보에는 영상 조각, 쿠키, 인증 헤더를 포함하지 않으며 URL의 사용자 이름·비밀번호·query·hash를 제거합니다.

DRM 및 이용 권한

표준 METHOD=AES-128 및 KEYFORMAT=identity HLS는 사용자가 VOD 전체 저장 또는 라이브 녹화를 시작한 경우 재생목록에 지정된 키 URI에서 16바이트 키를 가져와 브라우저 메모리의 Web Crypto로 조각을 복호화한 뒤 로컬에 저장합니다. 키 바이트와 키 주소는 로그나 영속 저장소에 기록하지 않으며 개발자 서버로 전송하지 않습니다. SAMPLE-AES, identity가 아닌 키 형식 및 DRM HLS는 지원하지 않습니다. 라이브 녹화는 미디어 순번을 안전하게 추적할 수 있는 단일/멀티플렉스 스트림만 지원하며 분리 오디오는 저장하지 않습니다. 로그인·지역·DRM 제한을 우회하지 않으며 권한 있는 미디어에 한해 사용해야 합니다. 표준 manifest 구조나 사이트 접근 정책이 다르면 지원되지 않을 수 있고 모든 사이트 호환을 보장하지 않습니다. 실패 시 이미 저장한 fMP4 조각은 Recovery Center에서 부분 복구할 수 있으며, Chrome 다운로드가 중단되면 이미 결합한 임시 MP4/MKV를 다시 저장할 수 있습니다. 라이브 녹화는 브라우저 재시작 후 자동 재개되지 않습니다. MPEG-TS 조각 수집 도중 브라우저가 재시작되면 partial TS는 Recovery Center에서 복구되지 않으며, 저장되지 않은 원격 구간은 다시 받거나 복구하지 않습니다.

광고와 프로파일링

처리 정보를 판매하거나 광고·프로파일링에 사용하는 기능은 없습니다.

Chrome Web Store 사용자 데이터 정책 (Limited Use)

Stream Recorder는 Chrome Web Store 사용자 데이터 정책의 Limited Use 요구사항을 준수합니다. 정보는 사용자가 권한 있는 웹 미디어를 선택한 형식으로 로컬 저장하는 단일 목적과 이를 수행하는 데 필요한 운영에만 사용합니다. 정보를 광고·프로파일링·판매에 사용하거나 개발자 서버로 보내지 않습니다. HLS 저장을 사용자가 직접 시작한 경우에는 그 기능에 필요한 재생목록·미디어 요청만 재생목록이 지정한 스트리밍 호스트로 전송합니다. 브라우저 쿠키나 서명 URL의 query가 해당 호스트에 전달될 수 있으며, 이는 사용자가 시작한 저장 작업을 수행하기 위한 것입니다.

보관과 삭제

녹화 세션과 임시 조각은 복구 또는 다운로드 완료 확인을 위해 브라우저에 남을 수 있습니다. 사용자가 자동 정리 옵션을 선택한 경우에도 다운로드 완료가 확인된 뒤에만 해당 임시 데이터가 정리됩니다. 그 외 정리는 관리 화면에서 사용자가 확인한 항목에 대해서만 수행됩니다. 녹화 중이거나 복구가 필요한 세션은 자동으로 삭제하지 않습니다.
